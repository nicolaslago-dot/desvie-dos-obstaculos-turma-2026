# Desvie dos Obstáculos Projeto da Turma 2026

## Sobre o projeto

Bem-vindos ao nosso projeto colaborativo de desenvolvimento de jogos!

Nosso desafio é desenvolver um **jogo interativo utilizando HTML, CSS e JavaScript**, no qual o jogador deverá desviar de obstáculos utilizando movimentos do próprio corpo.

A proposta é explorar criatividade, lógica de programação, design de interfaces e trabalho em equipe.

Este repositório será o espaço de desenvolvimento de toda a turma.

## O desafio

Imagine um jogo no qual você não precisa utilizar o teclado para movimentar o personagem.

O seu corpo será o controle!

A missão é construir uma experiência divertida, visualmente agradável e que responda às ações do jogador.

Para isso, teremos que pensar em diversos aspectos:

- Como será a aparência do jogo?
- Como os obstáculos aparecerão na tela?
- Como o jogador saberá que está indo bem?
- O que acontecerá quando ocorrer uma colisão?
- Como tornar a experiência divertida?
- Como conectar diferentes partes desenvolvidas por equipes?

**Não existe uma única solução correta.** Cada equipe deverá pesquisar, experimentar e justificar suas escolhas.

## Tecnologias

- HTML - Estrutura das páginas
- CSS - Aparência e animações
- JavaScript - Interações e comportamentos
- Git e GitHub - Versionamento e colaboração

## Organização

O desenvolvimento será dividido em duas equipes: **CSS**, responsável pela interface, e **JavaScript**, responsável pelo funcionamento do jogo. A equipe de JavaScript seguirá aulas guiadas, etapa por etapa; a equipe de CSS já pode montar as telas com autonomia.

As tarefas, a sequência das aulas de JavaScript e os testes de integração estão em [PLANO_DAS_EQUIPES.md](PLANO_DAS_EQUIPES.md).

As duas equipes deverão colaborar para que o resultado final funcione como um único jogo.

A detecção de movimentos corporais será desenvolvida e integrada pela coordenação técnica.

## Regras de colaboração

1. Cada equipe deverá trabalhar em sua própria branch.
2. Não alterem diretamente a branch `main`.
3. Antes de começar, atualizem seus arquivos com Git.
4. Escrevam mensagens de commit que expliquem o que foi alterado.
5. Evitem modificar arquivos de outras equipes sem conversar.
6. Ao concluir uma tarefa, abram um Pull Request.
7. Pesquisem e tentem resolver os desafios antes de solicitar a solução pronta.
8. Respeitem o trabalho dos colegas.

## O que esperamos das equipes?

- Participação dos integrantes
- Organização dos arquivos
- Código compreensível
- Comunicação entre equipes
- Criatividade nas soluções
- Comprometimento com as entregas

## Nosso objetivo

Mais importante do que terminar o jogo é aprender a **desenvolver software de maneira colaborativa**.

Ao final, teremos um projeto construído por diferentes pessoas, reunindo design, programação, criatividade e trabalho em equipe.

**O desafio começa agora!**
